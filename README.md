# 보랏빛 요새 탈출 작전

보랏빛 요새 탈출 작전(Escape from Violet Hold) 카드 데이터입니다.


## API 편집·경량화 지침 (2026-11-14)

- 공개 API는 `cards.json`(카드 ID와 현재 목록), `data/<CARD_ID>.json`(최초 한국 사용일과 날짜별 변경), `art/`(일반 카드), `golden/`(황금 원화·애니메이션), `frame/`(실제 카드 프레임·셰이더·텍스처)만 소비하도록 정리합니다.
- `render.json`, `history.json`, `*-date.json`은 중복 집계용으로 더는 커밋하지 않습니다. 빌드가 생성하더라도 검사용으로만 취급합니다. 카드별 JSON에 불필요한 schema/현재·과거 중복 래퍼를 새로 넣지 않습니다.
- 기존 `data/`가 날짜 키 형식이 아니라면 실제 날짜의 근거와 필드별 상태를 보존한 상태로 무손실 변환합니다. 출시 전 클라이언트 추가를 최초 사용일로 쓰지 않으며, KST·실제 이벤트 개방·모험 지구 개방·토큰 생성 가능일을 적용합니다.
- 오기입된 이전 날짜 키는 반드시 삭제/통합합니다. 추정 기록을 검증된 것으로 바꾸지 않습니다. 표시 줄바꿈은 `<br></br>`를 사용하고 황금/프레임 바이너리를 임의 수정하지 않습니다.
- `.github/`, 실제 필요한 `tools/`와 `release-policy.json`은 빌드 재현성을 위해 보존합니다. 원화·황금 카드·애니메이션·프레임 파일은 변경 전 소비 경로를 검사합니다.
